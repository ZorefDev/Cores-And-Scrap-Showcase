# Cores & Scrap Roguelite

**An independently developed isometric industrial vehicle roguelite.**


## About the Game

Cores & Scrap Roguelite is an isometric vehicle-combat game set in an industrial environment. Players fight enemies, collect resources, and progress through dangerous combat zones.

## Key Features

- Isometric vehicle-based combat.
- Multiple weapons and vehicle systems.
- Enemy AI and combat encounters.
- Room-based level progression.
- Resource collection and progression systems.
- Rewarded Advertisements: Integrated through Unity LevelPlay.
- Ad Mediation: Integrated Google AdMob and Unity Ads through LevelPlay.
